# Тасриф 2.0

Курс арабской морфологии (сарф) по учебнику «التصريف» (на основе «العزي في التصريف»), перестроенный по советам из `tasrif-course-guide.md`. Работает прямо в браузере, удобнее всего с телефона.

- 15 уроков, каждый в 6 шагов: начало (цели и «вспомним знакомое») → текст автора с переводом и источником → правило и где оно работает → разбор (полный → частичный → сам) → практика → итог (смешанная проверка)
- ввод форм с экранной арабской клавиатурой; проверка букв, шадды и обязательных харакатов
- при ошибке: где ошибка → подсказка → вторая попытка → ответ с объяснением → похожий пример
- раздел «Умения»: статус каждого умения и тренировка по нему
- повторение прошлых умений встроено в уроки, без карточек
- спрягатель и справочник, как в «Мизане»

Весь сайт — один файл `index.html`. Прогресс и попытки ученика хранятся в его браузере, аккаунты не нужны. Прогресс «Мизана» и «Тасрифа 2.0» хранится отдельно.

Выкладывается на GitHub Pages так же, как «Мизан»: отдельный репозиторий, загрузить `index.html`, `README.md`, `.nojekyll`, затем Settings → Pages → Deploy from a branch → main → / (root).

Исходники — в папке `../src`. Сборка: `python build.py`. Тесты: `cat stub.js check.js tests.js tests2.js > t_run.js && node t_run.js`.
