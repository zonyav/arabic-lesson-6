# Тасриф 2.0

Курс арабской морфологии (сарф) по учебнику «التصريف» (на основе «العزي في التصريف»), перестроенный по советам из `tasrif-course-guide.md`. Работает прямо в браузере, удобнее всего с телефона.

- 16 уроков, каждый в 6 шагов: начало (цели и «вспомним знакомое») → текст автора с переводом и источником → правило и где оно работает → разбор (полный → частичный → сам) → практика → итог (смешанная проверка)
- ввод форм с экранной арабской клавиатурой; проверка букв, шадды и обязательных харакатов
- при ошибке: где ошибка → подсказка → вторая попытка → ответ с объяснением → похожий пример
- раздел «Умения»: статус каждого умения и тренировка по нему
- повторение прошлых умений встроено в уроки, без карточек
- спрягатель и справочник, как в «Мизане»

Весь курс — в файле `index.html`. Прогресс и попытки ученика хранятся в его браузере, аккаунты не нужны. Прогресс «Мизана» и «Тасрифа 2.0» хранится отдельно.

## Файлы сайта

Кроме `index.html` в папке лежат файлы приложения: с ними сайт ставится на телефон как приложение и открывается без интернета. Шрифты лежат в папке `fonts`, поэтому сайт не зависит от Google Fonts. Загружайте на GitHub всё вместе: `index.html`, `manifest.webmanifest`, `sw.js`, четыре картинки `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` и папку `fonts` целиком (её можно перетащить в окно загрузки вместе с файлами).

При обновлении обычно меняется только `index.html`. Если после сборки изменились шрифты или иконки, загрузите заново и их.

Выкладывается на GitHub Pages так же, как «Мизан»: отдельный репозиторий, загрузить `index.html`, `manifest.webmanifest`, `sw.js`, четыре картинки `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` и папку `fonts` целиком (её можно перетащить в окно загрузки вместе с файлами), а также `README.md` и `.nojekyll`, затем Settings → Pages → Deploy from a branch → main → / (root).

Исходники — в папке `../src`. Сборка: `python build.py`. Тесты: `cat stub.js check.js tests.js tests2.js > t_run.js && node t_run.js`.
